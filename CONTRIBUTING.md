# Contributing

Install dependencies before you build or test. Run all commands from the repository root.

```sh
pnpm install
pnpm run build
pnpm run cover
pnpm run fix
pnpm run lint
pnpm test
```

See [AGENTS.md](AGENTS.md) for repository rules.
